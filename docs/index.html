GitKtti
Commands Install GitHub

kfeat, kfix, kreal, kfixend.

GitKtti runs git flow for you. Three commands open a feature, a hotfix or a release from the right branch. One command finishes any of them: it merges where git flow says to, tags master, and deletes the branch locally and on the remote.

$cpanm App::GitKtti

The commands

The short names are shell aliases you add yourself. Every command is installed as gitktti-* and answers --help.

  • kfeat

    Start a feature branch from develop.

    gitktti-fix --mode feature

  • kfix

    Start a hotfix branch from master.

    gitktti-fix

  • kreal

    Start a release branch from develop. It proposes the next version from the last tag.

    gitktti-fix --mode release

  • kfixend

    Finish the current branch: merge, tag if needed, delete it.

    gitktti-fixend

  • ktag

    Create and push a tag on master or main.

    gitktti-tag

  • kco

    Pick a branch from a list and check it out, remote ones included.

    gitktti-checkout

  • kmove

    Rename a branch locally and on the remote.

    gitktti-move

  • kdel

    Delete a branch locally and on the remote, after confirmation.

    gitktti-delete

  • kprune

    Remove local branches that are already merged.

    gitktti-fix --prune

  • ktest

    Check that your setup works.

    gitktti-tests

What it won’t let you do

GitKtti asks before anything irreversible, and refuses the mistakes git flow is built to prevent.

  • Finish a branch with uncommitted work

    kfixend checks the working tree first and stops if anything is left uncommitted.

  • Merge a feature into master

    Features go back to develop only. They reach master through a release.

  • Skip an open release

    If a release branch exists, a finished hotfix goes into that release instead of develop, so the fix ships with it.

  • Push develop into production by accident

    Finishing develop itself is possible, but you have to confirm twice: Are you sure to be sure?

  • Delete master or develop

    kdel and kprune never touch your two main branches.

Install

Needs Perl 5 and git. Works with master or main.

$ cpanm App::GitKtti
# or, without cpanminus
$ cpan App::GitKtti
$ git clone https://github.com/saumon/gitktti.git
$ cd gitktti
$ ./install.sh
$ perl Makefile.PL
$ make
$ make test
$ make install

Add the short names

Paste these into your ~/.bashrc or ~/.zshrc, then open a new shell.

alias kfeat='gitktti-fix --mode feature'
alias kreal='gitktti-fix --mode release'
alias kprune='gitktti-fix --prune'
alias kfix='gitktti-fix'
alias kfixend='gitktti-fixend'
alias ktag='gitktti-tag'
alias kco='gitktti-checkout'
alias kmove='gitktti-move'
alias kdel='gitktti-delete'
alias ktest='gitktti-tests'
